# Frontend Dashboard

This directory houses the frontend user interface for the Retail Transaction Analytics Platform.

## Technology Stack (Planned)
* Node.js v22.17+ / npm 8.19+
* React + Vite (or Next.js)
* Tailwind CSS / UI components
* Charting: Chart.js / Recharts

## Setup Instructions
When ready to initialize:
```bash
npm create vite@latest . -- --template react-ts
npm install
npm run dev
```
